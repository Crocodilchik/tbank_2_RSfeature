# План экспериментов, версия 1

Исходный ресурсный профиль исследования: RTX 3050 Laptop 4 GB, RAM около 16 GB. Все зависимости, данные и результаты создаются локально относительно каталога проекта.

## Исследовательская постановка

Один B0, четыре A1–A4, дополнительный контроль SFT. Порог потери NDCG@10: 2% относительно B0. Условие проверяется на V; при отсутствии допустимых вариантов выводится явный статус infeasible, выбирается диагностический вариант с максимальным NDCG без заявления об успехе.

В исходном parquet анализируются все event types. Модельный поток: listen; вне F для запросов используются recommendation-driven listens. История включает organic и recommendation listens. Лайки не дублируют прослушивания. Основная награда min(played_ratio/100,1). Значения >100 сохраняются в raw; такое ограничение — выбор цели, не очистка ошибок.

## Ресурсный дизайн

Smoke: стабильная hash-когорта около 100 пользователей, 2000 train-popular items, история 32, одна эпоха, 12 RL-обновлений, один seed. Study initial: около 1000 пользователей, 20000 items, история64, 2 слоя128/4heads. Когорта выбирается по неизменному хешу user-ID, не по будущей активности.

Временные границы .50/.55/.80/.90 по timestamp выбранной когорты. F/C/R/V/T. Они фиксируются до запуска моделей и метрик. Примеры обучения ограничены фиксированным числом на пользователя, равномерно по временной последовательности. Это ограниченная исследовательская выборка; не полное обучение на 50M.

Ресурсный probe сравнивает возможность полного каталога и уменьшенных вариантов. До фиксации основной конфигурации результаты scientific test не используются. Первый study config является предварительным и не утверждённым на основании полного hardware benchmark.

Лимит непрерывного runner:9.5ч; hard cap19.5ч. Проверяется между batch/stage, поэтому один нативный вызов может закончиться позже мягкой границы. Загрузка и установка учитываются отдельно. До длительного запуска нужен прогноз по измеренной скорости, при прогнозе >10ч сообщить пользователю.

## Метрики и выбор

Основной ranking: NDCG@10; Recall@5/10, coverage. Targets вне каталога дают ноль в unconditional метрике. RM-score и независимая диагностика не считаются реальной пользовательской наградой. Предыдущие треки разрешены, дубли внутри списка запрещены.

B0/A2/A3 используют top-K, A1 reranking, A4 Next-K; это сравнение законченных решений, не чистая оценка training objective. Для причинной интерпретации различий A4 требуется отдельный common-Next-K контроль. Нельзя объяснять разницу A4 только RL без этого контроля.

HPO: A1 alpha0/.5/2/8; A2 beta .01/.03/.1; A3 lambda0/.2/.5 при выбранном beta; A4 eta0/.05 при выбранных beta/lambda. Общие trials сохраняются. Выбор на seed42 по V, затем параметры фиксируются для43/44. Не считать trial caps одинаковыми затратами; публиковать фактическую стоимость.

Три seeds42/43/44. Среднее по запросам пользователя, затем по пользователям; training seed variance отдельно. Парный cluster bootstrap2000 для интервалов по пользователям, sign-flip тест при предположении exchangeability, Holm для4 сравнений с B0. При малом smoke всё описательно.

## Обязательные расширения до финальных научных выводов

Common-decoding; A4 horizons1/3/5 и eta0; вспомогательное supervised-обучение представления; выбор положительных действий; ratio vs seconds; длительность/популярность/repeats/personalization/cold/long-tail разрезы; prefix/provenance gates; фактический ресурсный отчёт. Невыполненные ячейки имеют статус pending, не successful.
